# Product Vision

Cash Flow Decision OS is not a generic cash flow dashboard. It is a weekly cash decision engine for owner-led SMEs.

## Primary User
Owner-led, job-based SMEs, especially specialty contractors, remodelers, fabrication businesses, countertop businesses, trades, and similar companies doing roughly $2M–$15M in revenue.

## Core Promise
Every week, the owner knows:
- Are we safe?
- When does cash get tight?
- Why?
- What should we collect, delay, protect, or monitor this week?
- What happens if we act?
- Did the action work?

## Core Loop
Data → Forecast → Explain → Decide → Simulate → Intervene → Verify → Learn

## Strategic Rule
The forecast is not the product. The weekly cash decision loop is the product.

## Product Principles
- Simplicity first.
- Do not build generic SaaS dashboards.
- Do not add complexity before the core weekly decision loop works.
- Prefer deterministic, explainable logic before machine learning.
- Human approval is required before execution.
- Forecast risk must lead to specific recommended actions.
- Recommended actions must eventually be simulated and verified.
- The app must build user trust within 60 seconds.
- Avoid over-architecture.
- Preserve current working functionality unless there is a clear reason to change it.

## Current Product Maturity
- Early pilot / founder-led prototype
- Strong deterministic forecast foundation
- Action engine and simulation loop are emerging but not complete
- Verification loop is a future moat and should be prioritized after the basic action loop works

## Do Not Build Yet
- Full autonomous execution
- Complex Markov chain engine
- Deep learning forecasting
- Overbuilt dashboards
- Multi-agent orchestration
- Full QuickBooks dependency before pilot learning
