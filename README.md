# Cash Flow Decision OS

Cash Flow Decision OS is a weekly cash decision engine for owner-led SMEs, not a generic cash flow dashboard.

## Core Product Loop
Data → Forecast → Explain → Decide → Simulate → Intervene → Verify → Learn

## Tech Stack
Next.js, TypeScript, Prisma, PostgreSQL/Neon, Clerk Organizations, Vercel

## Quickstart
```bash
npm install
npm run dev
npm run build
```
